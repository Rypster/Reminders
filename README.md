# InJeHoofd

Rustige PWA voor taken en ideeën.

## Tabs
- **Vandaag** – wat er vandaag speelt
- **Moet** – verplichtingen
- **Mag** – leuke dingen als je puf hebt
- **Idee** – hersenspinsels en concepten

## Installeren op Android
1. Open de site in Chrome
2. Menu → "Toevoegen aan startscherm" / "App installeren"

Alles wordt lokaal opgeslagen.
